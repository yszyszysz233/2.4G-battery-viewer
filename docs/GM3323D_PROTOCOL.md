# GM3323D 电量协议与验证记录

## 接口

- 实测产品字符串 `GM3323D`，厂商字符串 `DELL`。
- 2.4G 接收器：VID `1D57`、PID `FA60`。
- 仅监听 UsagePage `000A`、Usage `0000`、Input 长度 `5` 的集合。
- 同一接收器另有键盘、鼠标、消费者控制与 Feature 接口；不向这些接口发送命令。
- 配套程序还识别 PID `FA61` 为有线设备；本次没有验证有线电量或充电状态。

## 报文

```text
03 00 40 01 08
│  └─┬─┘ │  └─ 电量档位 8，即 80%
│    │   └──── 非零表示在线；零时不显示保留的电量字节
│    └──────── 小端事件类型 0x4000（也接受 0x4001）
└───────────── Report ID 3
```

配套程序把档位 1..10 乘 10 后显示。不能把第 4 字节直接当百分比，
也不能把 0、255 或其他越界值钳制成有效电量。
不从 0x4000/0x4001 的差异推断充电状态。

## 分析依据

[戴记严选 GM3323D 驱动页面](https://www.zanmson.cn/Drivers/MouseDriver/172.html)
提供的安装包仅在本地解包分析，没有安装或运行其中的程序；本仓库不包含其二进制文件。

解包后 `GM3323D.exe` SHA256：
`d80c0d36365bb682b64d598153a309caa4fd382dfa6992a7636abc7f6cab0a50`

该 32 位程序的相关地址（ImageBase `0x400000`）：

- `0x415D98` / `0x415DA4`：接受事件 `0x4000` / `0x4001`。
- `0x415E66`：低字节为在线状态，高字节为电量档位。
- `0x415F48`：验证电量档位为 1..10。
- `0x416C90`：档位乘 10，更新百分比显示。
- `hiddriver_1.dll` 的 `0x10001B47`：Input Report ID 3；字节 1..2
  组成事件类型、字节 3..4 组成事件值。
- 同 DLL 的 `0x10001E1F`：监听 UsagePage `000A`、Usage `0000` 的接口。

## 本次实机验证（2026-10-19）

- Windows、本机真实 GM3323D 接收器：多次收到 `03 00 40 01 08`，解读为 80%。
- 用户确认捕获时未插充电线、正在无线使用。
- 只读命令行及调试版策略均返回 80%。
- 仅调用 `ReadFile` 监听 Input Report；适配模块不调用 SetFeature/WriteFile。
- 其余档位、离线、超时、异常与格式错误使用自动化测试覆盖。
- 尚未实机验证从满电到低电的完整变化、关机/休眠切换、有线充电；
  不把测试构造的报文说成实机捕获结果。

每次刷新最多等待 5 秒。未连接、超时或报文无效时显示未知，不沿用上次成功百分比。
